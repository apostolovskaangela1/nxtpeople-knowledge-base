# Tab: Communication overview

# Communication

**Where:** Sidebar › **Communication** 

**Purpose:** See every message sent between your company and talents (SMS, email, WhatsApp) in one place, and check whether it was delivered.

![Communication screen overview with filters, message list and conversation panel](../images/NxtPlan/Communication_overview/image-20261118-093815.png)

## What you see

- **Filters** ①: dates, direction, board, talent and search.
- **Message list** ②: one row per message, newest first. More rows load as you scroll down.
- **Conversation** ③: all messages with the talent of the selected row. When you open the screen, the first row is selected.

## The message list

![Message list rows with incoming and outgoing direction arrows](../images/NxtPlan/Communication_overview/image-20261118-093857.png)


| Column | Shows |
| --- | --- |
| **Sending time** ① | Date and time sent (DD/MM/YY HH:mm) |
| **Direction** | ← **Incoming** ② (from the talent) or → **Outgoing** ③ (to the talent) |
| **Sender** | Who sent it. A list icon and the board name ④ means the board sent it automatically |
| **Receiver** | Who received it |
| **Content** | Message type icon, delivery status icon and the message title |
| **Sent by** | The board or pool the message came from. On smaller screens, scroll the list to the right to see it |

Hover the arrow to see the direction.

## The conversation

Click a row ① to open that talent's conversation. It jumps to that message ② and highlights it for a moment.

![Selected message row highlighted in the conversation panel](../images/NxtPlan/Communication_overview/image-20261118-094348.png)

- Messages are grouped by day, with the date in a grey label (e.g. **13/03/2026**).
- Messages to the talent are on the left. Messages from the talent are on the right, next to their initials.
- Scroll up to load older messages.
- You can only read messages here. You can't send them from this screen.

## Filters

| Filter | Use it to |
| --- | --- |
| **From** / **To** | Show messages sent between two dates. Click **×** to clear a date |
| **Incoming / Outgoing** | Show only messages from talents, or only messages to talents |
| **Sent from board** | Show only messages from one board. The board you have open is selected when you open the screen. Type to search for a board. Click **×** to see all boards |
| **Search candidate** | Show only messages with one talent. Type part of the name and pick the talent |
| **Search** | Find messages by words in the title or text, the talent's name, or the sender's name or email |
| ↺ (hover: **Clear filters**) | Reset all filters |

**From** ① is set to 12/03/2026. In the **To** calendar ②, the days before it are greyed out.

## Who sees this

- The **Communication** tab shows for everyone with access to at least one board, and for super admins.
- You only see messages:
    - with talents of your own company, sent from boards or pools you can view, or not linked to any board or pool;
    - from pools of other companies that you can view.
- **Anonymous talents:** their name is blurred.
- More on rights and companies: [Who sees what](https://file+.vscode-resource.vscode-cdn.net/Users/tamara.neshkovska/Downloads/NXTPLAN/docs/00-who-sees-what.md).

## On a phone

Messages show as cards: type, status, direction, time, title, **Sender**, **Receiver** and **Sent by**. There is no conversation panel.

## Good to know

- No results? The list says "No communication found. Click **here** to empty filter." Clicking **here** resets all filters.

![No communication found message with empty filter link](../images/NxtPlan/Communication_overview/image-20261118-094751.png)
