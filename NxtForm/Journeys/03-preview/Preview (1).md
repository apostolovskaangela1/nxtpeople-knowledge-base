# Preview \(1\)

Preview shows the candidate-facing journey for verification. Use it to review structure, language, content, navigation, questions, validation, media, and end behavior before publishing or sharing a journey.

#  Instructions

1. Open a journey. Insert screenshot: Journey open in Consultant
2. Select **Preview** or use a selected question/module Preview control. Insert screenshot: Preview button or module-level Preview control
3. Choose the team and language. Insert screenshot: Team and language selector
4. Open an embedded, new-tab, or copied Preview. Insert screenshot: Embedded Preview, new-tab option, and copy link option
5. Move through the candidate experience. Insert screenshot: Candidate-facing journey page in Preview
6. Verify content and behavior. Insert screenshot: Example validation, navigation, or media check
7. Return to Modify if a correction is needed. Insert screenshot: Return path to Modify

**Important safety distinction:** Preview is not the same as live candidate submission.

- It uses a preview key and Preview watermark.
- Normal answer posting is skipped in Preview navigation.
- Required HTML validation is disabled in several components.
- Synthetic variables may appear for candidate names.

Do not enter real candidate personal data or treat Preview completion as proof of submission persistence.

# Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Team/language row | Candidate preview context | Choose team and language |
| Embedded Preview | Candidate UI inside Consultant | Inspect layout and interactions |
| New-tab Preview | Full candidate route | Test independently |
| Copy link | Copies team/language preview URL | Share internally for approved testing |
| Candidate step/page/module | Candidate-facing journey structure | Navigate and test content |
| Answer controls | Candidate input/choice elements | Enter synthetic test values |
| Validation | Missing/invalid candidate input feedback | Check normal and preview behavior |
| End screen | Journey completion display | Verify text, button, and external actions |

# What you see first

After selecting **View preview**, NxtForm first shows a team/language selection table.

The table contains:

- tenant/team name
- team email
- embedded preview eye icon
- open-in-new-tab arrow icon
- copy-link icon

That screen is correct; it is the entry point to Preview, not the candidate Journey itself.

To open the candidate-facing Journey:

1. choose the correct team row
2. select the eye icon for embedded Preview or the external-arrow icon for a new tab
3. select the required language if prompted
