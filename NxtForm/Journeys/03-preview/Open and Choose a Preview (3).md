# Open and Choose a Preview \(3\)

Use this guide to open a Journey Preview, choose the correct team and language, and launch the preview in the format that best fits your testing task. A Preview starts from a journey-team preview key and optional language, and it can open at the journey start or at a specific step, page, or module.

**Screenshot placement:** Add screenshots at each callout marked **Screenshot**. Use annotations to highlight the Preview tab, action icons, language menu, and embedded size controls.

#  Instructions

## What the Preview tab shows first

The Preview tab first displays a table of Journey teams, not the candidate-facing questionnaire itself.

The visible overview includes:

- **Name** — tenant and team, such as NxtPeople - Special Forces
- **E-mail** — team email used for the team context
- an embedded-preview eye icon
- an open-in-new-tab arrow icon
- a copy-link icon

This table is the entry point to Preview. It does not yet show Journey steps, questions, answers, or the candidate end screen.

## Open the candidate-facing Preview

1. Stay in the **View preview** tab.
2. Find the correct team row.
3. Select the eye icon to open the candidate view in the embedded preview area.
4. If the eye action shows a language menu, select the intended language.
5. The candidate-facing Journey appears below or inside the preview area.

If you expected the Journey content immediately:

- confirm that you selected the eye action rather than only opening the Preview tab
- confirm the team preview key is available
- confirm a language is selected

## Opening from the Preview tab

Open a journey and use the Preview tab to access team-specific preview options.

1. Open a journey.
2. Select **Preview**.
3. Review the team table.
4. Confirm the team name, tenant, and email.
5. Open the language menu for Embedded Preview, New Tab, or Copy Link.
6. Select the intended language.

## Embedded Preview

The eye icon opens an iframe in the Consultant page.

Available dimensions:

- mobile
- tablet
- desktop

The embedded Preview can be toggled closed using the eye-slash action for the active team and language.

Use Embedded Preview when you need to:

- compare responsive layouts
- stay in the Consultant workflow
- inspect team and language context without leaving the Journey

## Open in a new tab

The external-arrow icon opens the candidate Preview URL in a new browser tab.

Use this when:

- full-screen testing is needed
- browser or device behavior matters
- embedded iframe behavior may hide an issue

## Copy a Preview link

The copy icon copies a team- and language-specific URL.

Preview URL structure contains:

- journey ID
- preview query parameter
- language query parameter
- optional step, page, or module parameters

Only share copied Preview links through approved internal testing channels.

## Opening from a selected question or module

In Modify, you can attempt to start Preview at a specific location.

1. Open the intended step.
2. Select the question or module.
3. Use the Preview control.

The implementation adds these query parameters:

- step
- page
- module

This attempts to start Preview at the selected location.

Verify that:

- the selected step appears
- the selected page appears
- the selected module is visible or focused

If the route position is stale or invalid, the candidate UI applies fallback or start logic.

## Preview team keys

A preview key is a unique journey-team key generated by the backend.

It:

- identifies team and theme context
- allows preview before referrals exist
- is associated with the journey team, not a normal shareable referral
- can be copied or opened with language selection

## Missing preview key

If a team has no preview key:

- eye, open, and copy actions are disabled
- the row is visually deactivated
- a no-preview-code tooltip explains the state

Do not create a normal referral as a substitute unless the approved workflow explicitly requires it. A preview key is managed by the journey-team mechanism.

## Legacy Preview route

Legacy referral parameters such as preview, key, language are redirected to the current query-parameter format.

This preserves older bookmarks and copied links, but it should not be used for new documentation links.

## Practical notes

- Choose team before language.
- A team and language combination determines theme, tenant, and candidate text.
- A question-level entry should be verified for exact step, page, or module start.
- Preview links are test routes, not normal customer referral links.

## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Team row | One journey-team preview context | Choose its preview and language actions |
| Embedded eye | Opens or closes an embedded candidate preview | Compare layouts inside Consultant |
| Open arrow | Opens preview in a new browser tab | Test the full-screen candidate experience |
| Copy icon | Copies the team- and language-specific preview URL | Share an approved test link |
| Language menu | Available journey languages | Choose candidate text and language |
| Dimension controls | Mobile, tablet, and desktop embedded size options | Test responsive presentation |
