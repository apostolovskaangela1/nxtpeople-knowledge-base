# Referral Codes \(1\)

Referral Codes manages the entry points that direct candidates into a journey. Use this landing page to choose the workflow you need.

# Start here

1. Open a journey.
2. Select **Referral codes**.
3. Review the creation form and Existing referral codes table.
4. Choose create, review, or modify based on the task.

# Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Add referral form | Creates a shareable referral for an eligible journey state | Enter required values and save |
| Existing referral codes | Lists referral entries associated with the journey | Review, copy, open, or edit entries |
| Referral code | Candidate entry identifier | Review and use in links |
| Tenant – Team | Referral ownership context | Confirm the correct journey-team |
| Referral type | Channel/source category | Confirm the referral purpose |
| Language | Candidate/referral language | Select or verify the expected language |
| NxtPlan pool | External candidate pool destination | Configure if NxtPlan sending is required |

# Practical notes

- Creation is usually available only for ongoing journeys and permitted users.
- Codes are unique within a journey-team context.
- Existing shareable entries support in-row editing; non-shareable entries have narrower edit rules.
- A referral can affect candidate attribution, notifications, reporting, and NxtPlan delivery.
