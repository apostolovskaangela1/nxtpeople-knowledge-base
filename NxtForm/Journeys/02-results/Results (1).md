# Results \(1\)

The Results tab is the operational workspace for reviewing submissions made or in progress for a selected Journey.

Use this hub to choose the task you need. Detailed guides explain the table, filters, candidate drawer, state, validation, reminders, bulk actions, deletion, export, pagination, and troubleshooting.

# Start here

1. Open a Journey.
2. Select **Results**.
3. Search or filter the submission list.
4. Review candidate identity, progress, state, and activity.
5. Open a candidate drawer for details.
6. Perform only the permitted validation, reminder, export, status, or delete action.
7. Verify the updated table, drawer, history, or external system result.

# Elements and meanings

| Element | Meaning | Main use |
| --- | --- | --- |
| Candidate | Submission/person identity context | Open and review one submission |
| Submission | One Journey participation record | Review answers, state, history, and actions |
| Progress | Candidate-step progress | Identify reached, passed, failed, or awaiting steps |
| State | Last submission state | Filter or update workflow status manually |
| Validation | Candidate identity/submission validation status | Match candidate or post candidate data |
| Referral | Entry/referral context | Attribute candidate source, team, or code |
| Note | Internal submission commentary | Record and review operational context |
| History | Submission occurrence log | Understand states, answers, notifications, and comments |

# What Results does not replace

- **Modify** changes Journey structure and questions.
- **Preview** tests the candidate-facing experience.
- **Results** reviews submissions and performs permitted operational follow-up.
