# Journeys: Icons and Header Actions \(7\)

Journey icons provide quick navigation and administrative actions. Hover over an icon to reveal its tooltip when available, then confirm which journey or row is selected before acting.

# Instructions

## Journey overview icons

In the overview, icons or controls may provide:

- search
- sort
- filters
- create/add
- export or administrative actions

Use Journey overview for the overview controls that have confirmed behavior.

## Opened journey header icons

| Icon/action | What it means | What happens |
| --- | --- | --- |
| Export | Starts journey export for authorized users | Download/export work begins according to permissions |
| Duplicate | Creates a copy of the journey | A confirmation modal appears; confirming starts duplication |
| History | Opens journey history | Shows recorded journey changes/activity |
| Settings | Opens journey settings | The settings drawer/panel opens for configuration |
| Feedback warning | Displays reviewer feedback for the journey | Expand/collapse to read reviewer comments |

Some header actions are permission or state dependent.

## Export a journey

Only users with the required admin/journey scope see Export.

1. Open the journey.
2. Select the export icon.
3. Wait for the export request.
4. Verify the downloaded/exported file or notification.

Do not export a journey when confidentiality, review state, or permissions are unclear.

**Screenshot placement:** Add one screenshot of the export icon before selection and, if available, one screenshot of the resulting export notification or downloaded file confirmation.

## Duplicate a journey

1. Open the journey.
2. Select Duplicate.
3. Read the confirmation text.
4. Confirm only if a separate copied journey is intended.
5. Check that duplication completes and opens or reports the copied journey.

Verify:

- journey name/context
- steps/questions
- settings
- teams/languages/referrals
- whether template-linked content requires separate review

## View journey history

1. Select the History icon.
2. Review chronological activity/change records.
3. Expand/collapse details if available.
4. Close the history panel to return to the journey.

## Open journey settings

1. Select the Settings icon.
2. Review the settings drawer.
3. Change only the permitted configuration.
4. Save/confirm according to the live drawer.
5. Return and verify the journey behavior/state.

## Step and question icons

Within Modify:

- grip handles reorder steps/modules/choices
- step three-dot menu opens duplicate/template/settings/delete actions
- question controls offer Preview, reset, duplicate, delete, media, video, PDF

Use the dedicated Modify steps, questions, and additional settings guides.

## Safe icon workflow

1. Hover to inspect tooltip text.
2. Read the dialog title before confirming.
3. Confirm the selected journey or row.
4. Review affected data/state.
5. Cancel if the outcome is unclear.
6. Verify the journey, row, or panel after the action.

## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Export icon | Starts journey export for authorized users | Download/export the selected journey |
| Duplicate icon | Creates a copy of the selected journey | Confirm and review the resulting journey |
| History icon | Opens recorded journey changes/activity | Review chronological context |
| Settings icon | Opens journey configuration | Change permitted settings and save |
| Feedback warning | Shows reviewer comments | Read/expand feedback before changing state |
| Grip handle | Reorders steps/modules/choices | Drag only in an editable context |
| Step three-dot menu | Opens step-specific actions | Duplicate, template, configure, or remove |
| Question controls | Preview/reset/duplicate/delete/media actions | Act on the selected question/module |
