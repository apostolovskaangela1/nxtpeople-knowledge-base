# Navigate Steps and Pages \(3\)

Use the left step sidebar to move through the journey. Use the page controls to move within a selected step.

# Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Step name | Identifies one higher-level journey section | Select it to open the step |
| Step grip handle | Drag control for step order | Reorder only in an editable journey |
| Step three-dot menu | Step-specific actions | Duplicate, template, reset, configure, or remove |
| Page navigation | Moves among pages in a step | Open a specific page |
| Module grip handle | Drag control for question/page-module order | Reorder modules where enabled |

# Navigate between steps

1. Open **Modify**.
2. Look at the left **Steps** sidebar.
3. Select the step name.
4. Confirm the active step name and language.
5. Review the main page and modules.

When a step changes, the route updates to the selected step/page.

# Navigate pages within a step

1. Open a step.
2. Use the page controls above or below the editor.
3. Move forward or backward through available pages.
4. Confirm that only modules assigned to the selected page are displayed.

# Reorder steps

1. Confirm the journey is editable.
2. Hold the six-dot grip beside the step.
3. Drag it to the intended position.
4. Release it.
5. Verify the sidebar order and Preview candidate navigation.

Reordering updates step sequences and the route position. Unsaved module edits should be completed or saved before reordering.

# Reorder modules/pages

1. Open the step and page.
2. Hold the module grip handle.
3. Drag the module/question to the intended position.
4. For page-level movement, verify page grouping and sequence.
5. Open Preview and confirm the candidate-facing order.

# Practical notes

- Step and module changes can affect later routing and conditional logic.
- Dragging is disabled for restricted/noneditable journeys.
- Verify every reorder in Preview.
