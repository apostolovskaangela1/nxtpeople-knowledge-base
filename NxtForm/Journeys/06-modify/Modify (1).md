## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Language tabs | Switches the active editing language | Edit step, question, description, and choice text |
| Steps sidebar | Lists journey steps | Navigate, reorder, duplicate, configure, or delete steps |
| Main editor | Shows pages/modules for the selected step | Edit question and content modules |
| Question card | One candidate-facing content or answer element | Open, edit, reorder, duplicate, or delete |
| Right-side settings | Configuration for the selected question or module | Change compatible type, property, media, score, or answer behavior |
| Anomalies overview | Reports missing or invalid configuration | Open and resolve the affected field |
| Preview | Shows the candidate-facing journey | Verify structure, text, choices, and navigation |

## Important limitations

- Editing availability depends on journey state, tenant permissions, review or add-on configuration, and templates.
- Exact live labels and control positions require signed-in screenshots before publication.
- Template-linked items may be restricted or editable only through master or template permissions.
- Saving is partly explicit and partly debounce or API-based; do not navigate away while feedback is pending.

## Practical notes

- Preview changes after saving or applying them.
- Verify language, journey version, required fields, and candidate-facing behavior.
