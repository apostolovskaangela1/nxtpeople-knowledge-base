# Understanding the Modify Interface \(2\)

The Modify tab combines three areas: a left step sidebar, a central page/editor area, and a right-side configuration panel for the selected question.

# Instructions

## Open the editing state

1. Open a journey.
2. Select **Modify**.
3. Confirm the journey name, language/version, team or tenant, and editable state.
4. Dismiss or address any warning that explains restrictions for the selected journey.

## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Language tabs | Selects the language currently being edited | Edit step, question, description, and choice text in that language |
| Steps sidebar | Lists and manages journey steps | Select, reorder, duplicate, configure, delete, or template a step |
| Step title | Names the selected step | Edit the name for the active language |
| Page navigation | Moves among pages in the selected step | Open each page and review its modules |
| Grip handles | Drag controls for steps, modules/pages, and choices | Reorder only while editing is allowed |
| Question card | A content, question, or answer module | Open and edit the selected module |
| Right-side settings | Configuration for the selected module | Change type, property, scoring, or choice settings where available |
| Anomalies overview | Highlights missing or invalid configuration | Open and resolve the indicated field |
| Preview control | Opens the candidate-facing experience | Verify the journey layout and behavior |

The interface warns if a journey is ongoing and live edits are restricted, is not editable in its current state, or has referral activity that may be affected. If editing is blocked, review Settings or tenant permissions. A warning is not permission to continue editing.

## Practical notes

- A step is a higher-level journey section.
- A page is a sequence within a step.
- A module or question is a content or interaction block on a page.
- Template-linked items may be restricted or editable only under template permissions.
