# Edit Language Content \(4\)

Journey text can be configured per language. The active language determines which step names, question titles, descriptions, and choices are edited.

#  Instructions

## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Language tab | The active localized editor language | Select text for that language |
| Step name field | The step label in the active language | Enter or change the label |
| Question title | End-user-facing title in the active language | Enter or update it |
| Description/content | Supporting instructions in the active language | Add or edit instructions |
| Choice text | Answer label in the active language | Add, edit, or translate answer text |

## Select a language

1. Open **Modify**.
2. Select the intended language tab above the editor.
3. Confirm the active language indicator.
4. Select the step, question, or choice to edit.

## Edit step names

1. Select the step title field.
2. Enter or change the title.
3. Continue or leave the field.
4. The field is patched for the active language.
5. Switch languages and verify the name or translation.

## Edit question titles and descriptions

1. Open the question card.
2. Edit the title.
3. Edit the description or content if needed.
4. Wait briefly for the debounce save.
5. Switch languages and verify localized content.

Title and description changes save after approximately 500 ms of inactivity. If saving fails, the editor reloads the saved server value.

## Edit choice text

1. Open the choice-based question.
2. Select the answer text field.
3. Enter or edit text for the active language.
4. Wait for the field-specific save.
5. Switch languages and verify the translated choice.

## Practical checks

- Do not leave required language fields empty unintentionally.
- Confirm translated terms reflect the same meaning.
- Verify Preview using the intended language.
- Verify candidate variables and dynamic text are available in the active language.
