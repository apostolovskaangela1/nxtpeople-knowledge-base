# Dashboard \(1\)

The Dashboard gives a quick operational overview of activity and submission status.

#  Instructions

1. Open **Dashboard** from the left navigation.
2. Choose **Influx** or **Candidates**.
3. Select **Year**, **Month**, and **Day** filters when needed.
4. Read the chart and status summaries for the selected period.

# What Dashboard is not

Dashboard is for overview and monitoring. It is not the primary place to edit candidates or journey records.

Use Dashboard to monitor reporting activity and status. Do not rely on it for routine record editing.

# Practical notes

- Dashboard is for reporting and monitoring, not routine record editing.
- Filter changes alter the visible operational summary.

# Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Dashboard | Operational overview of reporting activity | Read summaries and narrow the reporting period |
| Influx | Trend-oriented inflow/activity view | Compare activity over time |
| Candidates | Candidate-oriented status/activity view | Review candidate reporting segments |
| Year/Month/Day | Reporting-period filters | Narrow the visible dashboard data |
| Chart | Visual summary of a statistic | Compare values and inspect visible details |
| Submission status | Grouping of submissions by workflow state | Understand operational progress |
