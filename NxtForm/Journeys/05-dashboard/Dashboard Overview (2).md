# Dashboard Overview \(2\)

The Dashboard is an operational overview. It summarizes candidate or inflow activity and submission status for the selected reporting period.

**Screenshot placement guide:** Add a screenshot under each step where marked below. Use a cropped image that clearly shows the referenced area of the interface.

# How to use the Dashboard

## Step 1 — Open Dashboard

Select **Dashboard** in the left navigation.

## Step 2 — Choose Influx or Candidates

Use the top tabs:

- **Influx** — trend-oriented reporting of activity and inflow.
- **Candidates** — candidate-oriented reporting and status detail.

## Step 3 — Narrow the reporting period

Use **Year**, **Month**, and **Day** filters.

Apply filters one at a time and compare the chart before changing another filter.

## Step 4 — Read the dashboard

Review the chart and summaries for the selected tab and reporting period.

- Continue to Statistics
- Continue to Interactions

# Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Dashboard navigation | Opens the operational overview route | Switch from Journeys or Admin into reporting |
| Influx tab | Shows trend-oriented inflow data | Compare activity over time |
| Candidates tab | Shows candidate-oriented data | Review candidate and status reporting |
| Year filter | Sets the reporting year | Narrow the chart and summaries |
| Month filter | Sets the reporting month | Review a shorter period |
| Day filter | Sets the reporting day | Inspect one day of activity |
| Chart | Visualizes the selected reporting data | Compare values and use available detail controls |

# Practical notes

- Apply **Year**, **Month**, and **Day** progressively.
- Confirm whether **Influx** or **Candidates** is selected before interpreting statistics.

When comparing results, change one filter at a time so you can see what effect each filter has on the chart.
