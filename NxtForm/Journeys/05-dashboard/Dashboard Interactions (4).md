# Dashboard Interactions \(4\)

Use Dashboard as an overview and filtering surface, not as a form-editing screen.

#  Instructions

## Switch views

Select **Influx** or **Candidates** at the top of the page.

- **Influx**: volume and trend context
- **Candidates**: candidate and status context

## Filter the reporting period

Use the filters in this order for the clearest results:

1. Choose **Year**.
2. Choose **Month**.
3. Choose **Day**.
4. Review how the charts change.
5. Reset or change filters to compare a broader period.

- **Year** — select the reporting year
- **Month** — narrow to a month
- **Day** — narrow to a specific day

## Interact with chart and panel areas

When chart controls or hover details are available:

- Hover to inspect visible labels and tooltips.
- Select supported chart segments or drill-down controls.
- Return to the same reporting period before changing filters.

## Before taking an action

Verify the following first:

- the selected tab
- the reporting period
- the visible chart or panel
- whether the action opens detail or only changes filtering

Review filters and the active tab before using chart controls. Reset filters before comparing a broader period.

## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Influx tab | Reporting view for volume and trend activity | Switch to trend-oriented reporting |
| Candidates tab | Reporting view for candidate and status activity | Switch to candidate-oriented reporting |
| Year | Reporting-year selector | Narrow the dashboard period |
| Month | Reporting-month selector | Refine a selected year |
| Day | Reporting-day selector | Inspect one day |
| Chart segment | A category or time period in the visual summary | Hover or select only if drill-down is available |
| Tooltip | Context shown for a chart point or value | Inspect without changing data |
| Panel | A grouped dashboard statistic or operational summary | Read and compare with the selected filters |
| Reset or clear filter | Returns the dashboard to a broader period | Restore comparison context |
