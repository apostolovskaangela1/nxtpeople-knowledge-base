# Dashboard Statistics How\-To \(3\)

The Dashboard uses charts and summaries to show operational activity.

#  Instructions

## Influx statistics

The Influx view helps users understand reporting-period activity and volume over time.

**How to read it:**

1. Identify the reporting period.
2. Compare visible increases and decreases over time.
3. Use filters to confirm whether a change reflects time or selection.
4. Interpret each value as an activity summary, not candidate-level detail.

## Candidates statistics

The Candidates view helps users understand candidate-related activity and status.

**How to read it:**

1. Review candidate counts or status groups shown.
2. Compare the reporting view with the selected period.
3. Open or continue into deeper Journey or Result views when candidate-level detail is needed.

## Submission-status summary

The submission-status summary shows where records sit in the submission workflow.

**How to interpret it:**

1. Each visible status represents a progress category.
2. Counts reflect the selected reporting context.
3. Changes in filters may change the displayed status totals.

## Referral-code and operational panels

Any visible referral-code or operational panel should be read as context for candidate or submission activity. It helps identify a reporting segment but does not replace the detail available in Journeys or Results.

Exact statistic labels and chart values require the live reporting period. Apply filters and verify the visible chart or data before publishing a value-specific explanation.

## Practical notes

- Statistic values reflect the selected reporting period.
- Use Journey or Results for candidate-level detail.

## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Influx | Reporting trend for activity or inflow over the selected period | Compare volume over time |
| Candidates | Candidate-oriented reporting and status detail | Inspect candidate activity |
| Year | The reporting year used for the chart | Narrow dashboard data to that year |
| Month | The reporting month inside the selected year | Review a smaller period |
| Day | The reporting day inside the selected month or year | Inspect activity for one day |
| Chart | A visual representation of dashboard totals | Compare values and use visible hover or drill controls |
| Submission status | Counts or groups for where submissions sit in the workflow | Understand operational progress |
| Referral-code panel | Referral-related reporting context | Identify referral segments and open Journeys or Results for detail |
