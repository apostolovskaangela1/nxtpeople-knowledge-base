# Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Journey overview | Finds and opens journey records | Search, filter, sort, page, create, and open |
| Results | Reviews candidate submissions | Filter, open, validate, remind, export, or delete where permitted |
| Modify | Changes journey structure and content | Configure steps, pages, questions, answers, and settings |
| Preview | Shows the candidate-facing journey | Test layout, language, navigation, and validation |
| Referral Codes | Manages referral entries | Create and modify referral records |
| Header and row icons | Quick journey or record actions | Duplicate, history, settings, export, or row operations |
