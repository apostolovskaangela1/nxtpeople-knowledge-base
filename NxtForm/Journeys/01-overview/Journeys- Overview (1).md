# Journeys: Overview \(1\)

The Journeys overview is the starting point for finding, comparing, filtering, creating, and opening Journey records.

Use this page to decide whether to open an existing Journey or create a new one.

**Screenshots to add on this page:** Add screenshots in the marked callouts below for the full overview page, filters and sorting controls, Journey cards, and pagination/create actions.

# Start here

1. Select **Journeys** in the left navigation.
2. Review search, sort, and more-filters controls.
3. Narrow or sort the list.
4. Compare Journey cards.
5. Open the intended card.
6. Continue in [Results](../02-results/Results%20%281%29.md), [Modify](../06-modify/Modify%20%281%29.md), [Preview](../03-preview/Preview%20%281%29.md), or [Referral Codes](../04-referral-codes/Referral%20Codes%20%281%29.md).

# Core mental model

A Journey is a candidate-facing workflow with:

- a Journey type
- a lifecycle state
- tenant/team context
- languages
- steps and modules/questions
- referrals
- submissions and results

The Overview finds Journey records. It does not edit the selected Journey.

# Elements and meanings

| Element | Meaning | What the user can do |
| --- | --- | --- |
| Search | Finds Journey ID/name/version/customer/text matches | Enter text and wait for reload |
| Sort | Server-side ordering | Choose Last created, Last edited, or finished-submission volume |
| Journey type | Influx, Administration, or Registration purpose/category | Select one or more types |
| Journey state | Lifecycle/status: draft, waiting, ongoing, hidden, finished | Filter or interpret candidate availability |
| Archived switch | Include or hide soft-deleted/archive records | Switch between Hidden and Visible |
| Validation switch | Pending submission validation context | Choose All or Only pending |
| Journey card | Summary/navigation record | Compare and open the intended Journey |
| Paging | Moves through server-backed records | Open another 48-record page |
| Create + | Opens Journey creation | Create if create permission exists |
