# Dashboard Guide

# Dashboard

The Dashboard is the main operational overview in NxtForm. It gives the user a quick read on inflow, candidate activity, and submission status across the current reporting period. The page shown here is the live dashboard the user sees after sign-in.

## Where to find it

Users reach the Dashboard from the left-side navigation in the product. In the current UI, the navigation includes:

- Journeys
- Dashboard
- Admin
- Library

The route is the product overview area used after authentication, and the screen shown below is the live dashboard view.

## What users are expected to do

1. Open the Dashboard from the left navigation.
2. Review the selected reporting view: Influx or Candidates.
3. Use the filters for Year, Month, and Day to narrow the reporting context.
4. Interpret the chart and the submission-status summary before moving into a deeper workflow.

## What this module is for

The Dashboard helps users:

- review operational activity at a glance
- compare inflow trends over time
- inspect candidate status and referral-code activity
- understand current submission volume and pipeline state

## Typical workflow

### Step 1 — Open the dashboard

The user starts in the NxtForm dashboard area, which presents the main overview and filter controls.

### Step 2 — Choose the view

The user switches between Influx and Candidates depending on whether they want trend data or candidate-level detail.

### Step 3 — Narrow the reporting period

The user selects the Year, Month, and Day filters to review the relevant reporting window.

### Step 4 — Review the results

The chart, referral-code area, and submission-status summary show the current operational picture.

## Live dashboard screen

This dashboard is easiest to scan as a single full-page overview plus a few focused detail views.

### Navigation

What users see:

- the left navigation rail with Journeys, Dashboard, Admin, and Library
- quick access to the product areas the user works in most often

### Tabs

What users see:

- the Influx and Candidates views
- the active reporting mode for the current dashboard

### Filters

What users see:

- the Year, Month, and Day selectors
- the reporting timeframe that narrows the dashboard content

### Why this matters

The dashboard is the first operational overview for the user. It is where they confirm the current state of inflow and candidate progress before moving into more detailed work or administrative actions.

## Practical notes

- The Dashboard is a summary and monitoring screen, not a form-editing surface.
- The filters allow the user to narrow the reporting period and focus on the right moment in time.
- The visible panel structure is the main product overview for everyday operational review.
