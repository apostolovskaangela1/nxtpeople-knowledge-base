# Admin: Search and Tabs \(2\)

Use the search field and top tabs to narrow the Admin page to the correct organization view.

#  Instructions

## Open Admin

1. In the left navigation, select **Admin**.

## Choose [Companies](Admin-%20Companies%20%283%29.md) or [Customers](Admin-%20Customers%20%284%29.md)

Use the tab row at the top of the workspace:

- [**Companies**](Admin-%20Companies%20%283%29.md) shows organization or tenant records.
- [**Customers**](Admin-%20Customers%20%284%29.md) shows customer records managed within the admin workspace.

What to look for:

- ① [**Companies**](Admin-%20Companies%20%283%29.md) tab
- ② [**Customers**](Admin-%20Customers%20%284%29.md) tab
- the active tab, which identifies the list currently shown

Add screenshot: tab row showing Companies, Customers, and the active tab state

## Search organizations

Use **Search organization** to narrow visible organization records.

What users can search for:

- organization or tenant name
- text visible in the organization name or list

How to use it:

1. Select the search field.
2. Enter part or all of the organization name.
3. Review the filtered rows.
4. Clear the field to return to the full organization list.

## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Companies | Organization/tenant records | Review or, when permitted, edit company information |
| Customers | Customer records in the admin context | Filter, create, or edit customer records |
| Search organization | Finds matching organization/tenant names | Enter text and review matching rows |
| Active tab | Identifies the list currently shown | Confirm this before editing or comparing records |
