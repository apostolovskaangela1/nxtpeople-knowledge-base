# Admin: Companies \(3\)

**Purpose:** The **Companies** tab contains the organization or tenant table and company-management actions.

# Table headers

Use the headers to identify a company before opening or editing it.

| Header | Description |
| --- | --- |
| **Tenant** | The organization or tenant name shown in the table. |
| **Teams** | The number or summary of teams associated with the tenant. |
| **Consultants** | The number or summary of consultants associated with the tenant. |
| **Colour scheme** | The tenant’s configured visual color scheme. |
| **URL** | The tenant or organization access link. |

# Search within Companies

Use **Search organization** above the table to find a company by name or matching visible organization text.

# Edit a company

The exact edit icon and dialog labels still require a signed-in live capture. Use this workflow only after selecting the row’s edit action.

1. Find the company in the Companies table.
2. Select the edit/icon action shown on that company row.
3. Review the company details in the edit dialog.
4. Change only the fields that need to be corrected.
5. Confirm the values before saving.
6. Select the Save/Confirm action.
7. Return to the Companies table and verify the updated row.

# What to verify before saving

- Tenant/company name is correct.
- Teams and consultant context reflect the intended organization.
- Colour scheme is readable and matches the expected tenant setup.
- URL points to the intended organization access route.

## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Tenant | The organization/tenant identity shown in the row | Confirm the correct company context |
| Teams | Teams connected to the tenant | Review team scope |
| Consultants | Consultants associated with the tenant | Review consultant coverage |
| Colour scheme | The tenant’s configured visual brand palette | Confirm expected tenant colors |
| URL | The tenant/organization access address | Verify the intended access route |
| Search organization | Filters visible Companies rows | Enter organization text and review matches |
| Edit/action icon | Opens the row management workflow | Review or change permitted company values |
