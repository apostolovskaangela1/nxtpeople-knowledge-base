# Admin: Customers \(4\)

**Purpose:** This page documents the Customers tab in Admin and marks where live product screenshots must be added before publication.

# Overview

The **Customers** tab contains the customer list and the filtering and actions used to create or edit customer records.

## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Customers tab | Switches the Admin list from companies to customer records | Open it when the task concerns customers |
| Filter controls | Narrow the customer list by the configured field/value | Apply one filter at a time and reset to compare the full list |
| Customer row | One customer record in the table | Review or open its edit/action workflow |
| Create/Add customer | Starts a new customer record | Enter required and optional fields, then save/create |
| Customer name/title | The identifying name of the customer | Enter or correct the customer identity |
| Organization/company | The tenant or company context connected to the customer | Confirm the correct organization before saving |
| Account/contact information | Values used to identify or reach the customer | Enter only verified customer details |
| Status/enabled setting | Whether the customer is active or available in the configured workflow | Review before saving and change only when intended |
| Edit/action icon | Opens the selected customer’s edit workflow | Update permitted fields and save |
| Save/Create | Confirms and stores the completed record | Use after all required fields and context are correct |

**Live capture required:** Exact filter labels, action names, icons, field names, required values, and interface screenshots must be confirmed in a signed-in environment.

# Filter customers

Use the visible filtering controls in the Customers tab to narrow the customer list.

1. Open the Customers tab.
2. Select the filter control needed for the customer list.
3. Choose or enter the filter value.
4. Review the filtered rows.
5. Clear or reset the filter to restore the broader list.

Exact customer filter labels and screenshots require a signed-in live capture.

# Create a customer

1. Open the Customers tab.
2. Select the Create/Add customer action.
3. Enter the customer’s required identifying information.
4. Review organization, tenant, or account values shown in the form.
5. Confirm the details are correct.
6. Select Save/Create.
7. Verify the new customer appears in the customer list.

## Input groups to verify

- Identifying customer name or title
- Associated organization/company context
- Required account/contact information
- Status or enabled/disabled setting, if shown

Exact field names and required values must be copied from the live dialog before publication.

# Edit a customer

1. Find the customer in the customer table or filtered results.
2. Select the row edit/action icon.
3. Review the existing values in the edit dialog.
4. Change only the fields that need updating.
5. Confirm the correct organization/customer context.
6. Select Save/Confirm.
7. Return to the customer list and verify the updated row.
