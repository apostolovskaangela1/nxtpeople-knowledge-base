# Admin Area Guide \(1\)

The Admin area is the organization-management workspace in NxtForm. It brings company and tenant records together with customer records behind the left-navigation **Admin** entry.

Use Admin when you need to review organization records, locate a specific company or customer, or open the correct workflow to edit or create records.

#  Start here

1. Open **Admin** from the left navigation.
2. Choose [**Companies**](Admin-%20Companies%20%283%29.md) or [**Customers**](Admin-%20Customers%20%284%29.md).
3. Use [search and filtering](Admin-%20Search%20and%20Tabs%20%282%29.md) to narrow the list.
4. Open the relevant edit or create workflow only after confirming the correct record.

#  What this area is for

## Elements and meanings

| Element | What it means | What the user can do |
| --- | --- | --- |
| Companies | Organization/tenant administration view | Search, review, and edit permitted company records |
| Customers | Customer administration view | Filter, create, and edit permitted customer records |
| Search | Narrows the selected Admin list | Enter matching organization/customer text |
| Table row | One company or customer record | Review or open the available row action |
| Filter | Narrows a visible list | Choose or reset a configured filter |
| Edit/action icon | Opens the management workflow for a row | Change or review permitted values |
